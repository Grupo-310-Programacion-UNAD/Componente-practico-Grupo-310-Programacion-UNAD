# Componente práctico - Grupo 310 Programación UNAD

## Descripción del proyecto

Este proyecto corresponde al componente práctico del curso de Programación de la UNAD, desarrollado por el Grupo 310. La aplicación fue diseñada utilizando programación orientada a objetos, implementando principios como encapsulación, herencia, abstracción y polimorfismo, además del manejo avanzado de excepciones para garantizar la estabilidad y robustez del sistema.

El sistema permite gestionar clientes, servicios y reservas para la empresa Software FJ, simulando diferentes operaciones válidas e inválidas sin utilizar bases de datos, haciendo uso únicamente de objetos, listas y archivos de registro.

---

## Objetivos del proyecto

- Aplicar los conceptos de programación orientada a objetos.
- Implementar manejo de excepciones y validaciones.
- Desarrollar un sistema estable y robusto.
- Trabajar colaborativamente mediante GitHub.
- Documentar y organizar adecuadamente el código del proyecto.

---

## Funcionalidades principales

✔ Registro de clientes  
✔ Gestión de servicios  
✔ Creación de reservas  
✔ Validaciones de datos  
✔ Manejo de errores y excepciones  
✔ Registro de eventos y errores en logs  
✔ Simulación de operaciones válidas e inválidas
